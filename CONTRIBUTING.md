# Contributing to SkinMind Project

Thank you for your interest in contributing! We welcome all forms of contribution, from content creation to bug fixes and suggestions.

## Ways to Contribute

### 1. **Share Your Story**
- Submit personal experiences or testimonials (with consent)
- Help others feel less alone by sharing what helped you
- Folder: `/content/stories/`

### 2. **Create Educational Content**
- Write articles about dermatillomania
- Explain scientific findings in accessible language
- Highlight lesser-known aspects of the condition
- Folder: `/content/education/`

### 3. **Share Coping Strategies**
- Document techniques that help manage urges
- Explain grounding exercises and mindfulness practices
- Share daily tools and habits that work
- Folder: `/content/coping-strategies/`

### 4. **Add Resources**
- Links to therapy, support groups, or research
- Professional organizations and helplines
- Books, podcasts, or documentaries
- Folder: `/content/resources/`

### 5. **Improve the Website**
- Design enhancements
- Accessibility improvements
- Bug fixes
- Better organization

## How to Contribute

### Step 1: Fork & Branch
```bash
git clone https://github.com/sunlium/skinmindproject.git
cd skinmindproject
git checkout -b feature/your-contribution-name
```

### Step 2: Make Your Changes
- Create files in the appropriate `/content/` folder
- Use clear, empathetic language
- Provide sources for medical/scientific claims
- Keep content accessible and non-judgmental

### Step 3: Create a Pull Request
- Describe what you've added
- Explain why this content is valuable
- Link any references or sources

### Step 4: Review
- We'll review your contribution
- May ask for adjustments for clarity or accuracy
- Once approved, it'll be merged and published!

## Content Guidelines

### Tone & Language

✅ **Do:**
- Be compassionate and non-judgmental
- Use person-first or identity-first language as appropriate
- Acknowledge that everyone's experience is different
- Provide evidence-based information

❌ **Don't:**
- Shame or stigmatize people with dermatillomania
- Present personal experience as universal truth
- Provide medical diagnoses or replace professional care
- Use sensationalist language

### Format
- Write in Markdown (.md files)
- Use clear headings and sections
- Include references and sources
- Keep paragraphs concise and readable

## Questions?
Open an issue in the repository and we'll help you get started!
